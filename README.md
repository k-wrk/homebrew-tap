# Homebrew Tap (`k-wrk/homebrew-tap`)

Official Homebrew Tap for **[k-wrk](https://github.com/k-wrk)** tools and utilities.

## How to Install

First, add this tap to your Homebrew installation:

```bash
brew tap k-wrk/homebrew-tap
```

Then install any of the available formulas:

```bash
brew install <formula>
```

---

## Available Formulas

| Formula | Version | Description | Install Command |
| :--- | :--- | :--- | :--- |
| **[`cinder`](https://github.com/k-wrk/cinder/)** | `1.0.1` | Interactive Terminal Utility for macOS Disk Cleanup | `brew install cinder` |
| **[`sub-llama`](https://github.com/k-wrk/Sub-LLama)** | `1.0.0` | Local subtitle translator and video muxer using CTranslate2 | `brew install sub-llama` |
| **[`tappub`](https://github.com/k-wrk/tappub)** | `1.0.0` | Agnostic CLI to publish and update Homebrew Tap formulas automatically | `brew install tappub` |

---

## Updating Formulas

To update installed tools to the latest release:

```bash
brew update
brew upgrade cinder
brew upgrade sub-llama
brew upgrade tappub
```
